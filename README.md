# Jarvis — локальний голосовий асистент

Голосовий помічник для Windows-ноутбука. Слух, голос, зір, пам'ять і інтерфейс працюють **локально на цьому ПК**.
Мозок — **Claude Code через вашу підписку Claude** (без API-ключа): Джарвіс запускає встановлений `claude` у фоні.

```
мікрофон ─► Silero VAD ─► Whisper (small, офлайн, ru) ─► «Джарвис…»? ─► Claude Code (підписка)
                                                                    │  ├─ PowerShell / Bash  (дії на ПК)
                                                                    │  ├─ Read кадру з камери (зір)
                                                                    │  └─ нотатки у workspace/vault (пам'ять)
динаміки ◄── Piper TTS (російський голос, офлайн) ◄── відповідь потоком, по реченнях
```

## Запуск

```bat
start.bat
```

Відкриється окреме вікно Джарвіса. Перший запуск триває ~20 с (завантаження моделей).

**Джарвіс слухає лише поки відкрите його вікно.** Мікрофон вмикається, коли вікно підключилося, і вимикається, щойно його закрили; через 5 секунд після закриття весь процес завершується сам.

Передумови (на цьому ПК вже є): Python 3.13 з пакетами з `requirements.txt`, Node.js, Claude Code, у який ви увійшли (`claude` → `/login`).

## Як говорити

| Спосіб | Що робити |
|---|---|
| Слово-активатор | «Джарвис, какая погода в Киеве?» — звертання має бути на початку (можна після «слушай», «эй») чи в кінці фрази; «я говорил с Джарвисом», «мне Джарвис сказал» ігноруються |
| Продовження | 10 секунд після відповіді можна говорити без «Джарвис» (після «Стоп» — ні) |
| Push-to-talk | утримуйте **F8** (працює в будь-якій програмі, поки вікно відкрите) або **Пробіл** / кнопку «Утримуйте» у вікні |
| Текстом | поле «Напишите Джарвису…» |
| Перервати | **Esc** або кнопка «Стоп» |

Приклади: «Джарвис, посмотри, что у меня в руках», «запомни, что я пью кофе без сахара», «открой YouTube», «сколько заряда у ноутбука», «запиши идею: …».

**Мова.** Джарвіс говорить і розуміє **російською**, увесь інтерфейс теж російською (`language: ru`).

## Можливості

- **Характер і гумор.** Повзунок 0–100 % у вікні: від сухого протоколу до сарказму й підколок. Говорить розмовно, як жива людина.
- **Мат.** Перемикач «Мат» у картці «Характер»: дозволяє міцне слівце в розмові (дозовано, без образ людей і груп). За замовчуванням вимкнено.
- **Зір.** Картка «Зір» (камера вимкнена за замовчуванням). Кадр іде в Claude тільки тоді, коли питання стосується того, що видно.
- **Пам'ять.** `workspace/vault/memory.md` — факти про вас, `workspace/vault/notes/` — нотатки. Звичайний markdown, папку можна відкрити в Obsidian.
- **Дії на ПК з дозволом.** Claude виконує команди PowerShell/Bash, шукає в інтернеті, читає файли. Безпечні команди (час, процеси, відкрити сайт чи звичайну програму) виконуються одразу. **Будь-яку іншу команду перехоплює хук** (`jarvis/approve_hook.py`): Джарвіс питає «Так чи ні?», а у вікні з'являється картка з командою й кнопками. Без відповіді за 90 с, після «Стоп» або при будь-якій помилці команда відхиляється.

## Налаштування — `config.json`

| Ключ | Що змінює |
|---|---|
| `claude_model` | `sonnet` (за замовчуванням), `haiku` — швидше, `opus` — розумніше й повільніше |
| `stt_model` | `small` — точніше (~4 с на фразу на цьому CPU); `base` — ~1,2 с, але більше помилок |
| `tts_voice` | `ru_RU-ruslan-medium` (найчіткіший), `ru_RU-denis-medium`, `ru_RU-dmitri-medium` (перемикається і у вікні; завантаження — `python -m jarvis.setup_models`) |
| `wake_words` | варіанти написання «Джарвис», які Whisper може видати |
| `follow_up_seconds` | скільки секунд після відповіді слухати без слова-активатора |
| `ptt_key` | клавіша push-to-talk (`f8` за замовчуванням, `ctrl_r`, …; `null` — вимкнути) |
| `profanity` | `true` — дозволити мат (перемикається і у вікні) |
| `mic_device`, `output_device` | номер пристрою (список: `python -c "import sounddevice; print(sounddevice.query_devices())"`) |
| `claude_allowed_tools` | інструменти, доступні Claude (shell-команди все одно проходять через дозвіл) |
| `claude_disallowed_tools` | заборонені інструменти й шляхи (`~/.claude`, `~/.ssh`, `~/.aws`, `~/AppData` закриті для читання) |

## Важливо знати

- **Підписка.** Використовується незмінений `claude` з вашим входом — так дозволяють [правила Anthropic](https://code.claude.com/docs/en/legal-and-compliance) для особистого використання. Не давайте доступ до Джарвіса іншим людям.
- **Ліміти.** Кожна репліка витрачає ліміт підписки, як звичайне повідомлення в Claude Code. Те, як Anthropic рахує фонові (`-p`) запуски, може змінюватися — стежте за використанням у налаштуваннях акаунта.
- **Ваш глобальний `~/.claude/CLAUDE.md` Джарвісу не передається** (виключено через `claudeMdExcludes`), і глобальні хуки теж (`--setting-sources project`).
- **Безпека.** Запис файлів дозволено лише в `workspace/vault`; shell-команди проходять через хук дозволу (див. вище). Якщо хочете ще суворіше — приберіть `Bash`/`PowerShell` з `claude_allowed_tools`.
- **Мікрофон працює лише при відкритому вікні**, усе розпізнається локально; у журналі фрази без звертання позначені «ПОЧУТО» і нікуди не надсилаються.
- Керувати Джарвісом може лише його власне вікно (127.0.0.1, перевірка Host і точного Origin); ендпоінт дозволів захищений одноразовим токеном.

## Розробка

```bat
python -m pytest -q tests          :: тести логіки
python -m jarvis --no-window       :: ядро без автозапуску вікна (відкрийте http://127.0.0.1:8765 вручну)
cd ui && npm run dev               :: інтерфейс з гарячим перезавантаженням (http://localhost:5173)
```

Структура: `jarvis/brain.py` (Claude), `ears.py` (мікрофон, VAD, Whisper), `voice.py` (Piper), `eyes.py` (камера), `core.py` (стани, слово-активатор, PTT), `server.py` (міст до вікна), `persona.py` (характер і пам'ять), `ui/` (React + Three.js).
