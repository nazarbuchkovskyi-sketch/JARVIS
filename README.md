# Jarvis — локальний голосовий асистент

Голосовий помічник для Windows-ноутбука. Слух, голос, зір, пам'ять і інтерфейс працюють **локально на цьому ПК**.
Мозок — **Claude Code через вашу підписку Claude** (без API-ключа): Джарвіс запускає встановлений `claude` у фоні.

```
мікрофон ─► Silero VAD ─► GigaAM v3 (офлайн, ru, ~0,3 с) ─► «Джарвис…»? ─► Claude Code (підписка)
                                                                    │  ├─ PowerShell / Bash  (дії на ПК)
                                                                    │  ├─ Read кадру з камери (зір)
                                                                    │  └─ нотатки у workspace/vault (пам'ять)
динаміки ◄── Piper TTS (російський голос, офлайн) ◄── відповідь потоком, по реченнях
```

## Найпростіше: через Claude Code

Відкрийте Claude Code на Windows-ПК і напишіть:

> https://github.com/nazarbuchkovskyi-sketch/JARVIS — склонуй і запусти

Claude прочитає [`CLAUDE.md`](CLAUDE.md) у цьому репозиторії і сам усе встановить, перевірить і запустить. Потрібна лише підписка Claude (Pro/Max), у яку ви увійшли в Claude Code.

## Встановлення з нуля вручну (Windows 10/11)

Потрібно один раз поставити:

1. **Python 3.13** — [python.org](https://www.python.org/downloads/), при встановленні поставте галочку «Add python.exe to PATH».
2. **Node.js LTS** — [nodejs.org](https://nodejs.org/) (потрібен лише для збірки інтерфейсу).
3. **Claude Code** — [інструкція](https://code.claude.com/docs/en/setup), потім у терміналі `claude` → `/login` і вхід у свій акаунт з підпискою Claude (Pro/Max). API-ключ не потрібен.
4. **Microsoft Edge** (є у Windows за замовчуванням) — у ньому відкривається вікно Джарвіса.
5. Мікрофон, динаміки або навушники, вебкамера.

Потім:

```bat
git clone https://github.com/nazarbuchkovskyi-sketch/JARVIS.git
cd JARVIS
.setup.bat
```

`setup.bat` ставить Python-пакети точних версій (`requirements.txt`), збирає інтерфейс і завантажує моделі: голос Piper `ru_RU-denis-medium` (~60 МБ) і розпізнавання мови GigaAM v3 (~850 МБ, у `~/.cache/huggingface`). Займає 5–15 хвилин залежно від інтернету.

## Запуск

Двічі клікніть **`Jarvis.vbs`** — Джарвіс запуститься без вікна терміналу, з'явиться лише його вікно (запуск ~20 с).
`start.bat` робить те саме, але з видимою консоллю (зручно, щоб бачити журнал наживо). Журнал завжди пишеться в `logs\jarvis.log`.
Скажіть «Джарвис, привет».

**Джарвіс слухає лише поки відкрите його вікно.** Мікрофон вмикається, коли вікно підключилося, і вимикається, щойно його закрили; через 5 секунд після закриття весь процес завершується сам.

Перевірка, що все стоїть правильно: `python -m pytest -q` (тести не чіпають мікрофон і камеру).

## Як говорити

| Спосіб | Що робити |
|---|---|
| Слово-активатор | «Джарвис, какая погода в Киеве?» — звертання має бути на початку (можна після «слушай», «эй») чи в кінці фрази; «я говорил с Джарвисом», «мне Джарвис сказал» ігноруються |
| Продовження | 20 секунд після відповіді можна говорити без «Джарвис» (після кнопки «Стоп» — ні) |
| Перебити | просто говоріть поверх нього; «стоп», «хватит», «погоди» — замовкне |
| Push-to-talk | утримуйте **F8** (працює в будь-якій програмі, поки вікно відкрите) або **Пробіл** / кнопку «Утримуйте» у вікні |
| Текстом | поле «Напишите Джарвису…» |
| Перервати | **Esc** або кнопка «Стоп» |

Приклади: «Джарвис, посмотри, что у меня в руках», «запомни, что я пью кофе без сахара», «открой YouTube», «сколько заряда у ноутбука», «запиши идею: …».

**Мова.** Джарвіс говорить і розуміє **російською**, увесь інтерфейс теж російською (`language: ru`).

## Можливості

- **Характер і гумор.** Повзунок 0–100 % у вікні: від сухого протоколу до сарказму й підколок. Говорить розмовно, як жива людина.
- **Мат.** Перемикач «Мат» у картці «Характер»: стиль «братан», міцне слівце для емоції (без образ людей і груп). За замовчуванням увімкнено.
- **Перебивання.** Говоріть поверх Джарвіса — він замовкає й відповідає на нові слова; «стоп», «хватит», «погоди» — просто замовкає. Його власний голос з динаміків відфільтровується за текстом (у навушниках працює найнадійніше).
- **Сам коментує.** Перемикач «Сам коментирует»: коли 35–70 с тиша, Джарвіс дивиться в камеру й кидає підкол по деталях кадру (або мовчить, якщо нема чого сказати). Якщо його ігнорують — говорить рідше.
- **Зір.** Картка «Зір» (камера увімкнена за замовчуванням). Кадр іде в Claude, коли питання стосується того, що видно, і для реплік «Сам коментирует».
- **Пам'ять.** `workspace/vault/memory.md` — факти про вас, `workspace/vault/notes/` — нотатки. Звичайний markdown, папку можна відкрити в Obsidian.
- **Дії на ПК з дозволом.** Claude виконує команди PowerShell/Bash, шукає в інтернеті, читає файли. Безпечні команди (час, процеси, відкрити сайт чи звичайну програму) виконуються одразу. **Будь-яку іншу команду перехоплює хук** (`jarvis/approve_hook.py`): Джарвіс питає «Так чи ні?», а у вікні з'являється картка з командою й кнопками. Без відповіді за 100 с, після «Стоп» або при будь-якій помилці команда відхиляється.

## Планер (Planning System) — лише читання

Джарвіс може читати ваш планер (календар тижня, to-do, задачі, фокус тижня) з його Postgres і **нічого там не змінює**.
«Джарвис, что у меня сегодня?», «что дальше?», «когда созвон с Владом?», «что на неделе?», «какие у меня задачи?».
За 10 хвилин до кожного блоку календаря він сам нагадує голосом (`planner_reminders` у `config.json`, `[]` — вимкнути, `[10, 0]` — ще й на старті).

Підключення (один раз):

1. Railway → сервіс **Postgres** → **Settings → Networking → Public Networking** → увімкнути TCP Proxy. З'явиться змінна `DATABASE_PUBLIC_URL` (адреса `…proxy.rlwy.net:порт`). `DATABASE_URL` з `railway.internal` ззовні не працює.
2. Скопіюйте значення `DATABASE_PUBLIC_URL` (Variables → ⋮ → Copy) і виконайте в папці Джарвіса:
   ```bat
   python -m pip install -r requirements.txt
   python -m jarvis.planner_setup --user Vlad
   ```
   Вставте рядок (ввід прихований). Скрипт створить у базі роль `jarvis_ro`, яка може тільки `SELECT` з `calendar_events`, `inbox_items`, `tasks`, `projects`, `week_plans`, `settings` (звідти береться лише часовий пояс) і `users(id, name, email, timezone)` (без хешів паролів), перевірить, що вона не може писати, і збереже її рядок підключення в `%APPDATA%\Jarvis\planner.env` — поза репозиторієм. Рядок адміністратора ніде не зберігається.
3. Перевірка: `python -m jarvis.planner_setup --check` — покаже сьогоднішні блоки і «Доступ только на чтение: OK». Потім перезапустіть Джарвіса: у картці систем з'явиться «План · Planning System · Vlad».

Захист у три шари: роль тільки з `SELECT`; кожне з'єднання з `default_transaction_read_only=on` і кожен запит у `READ ONLY`-транзакції, яка відкочується; Claude не пише SQL — у нього лише 7 фіксованих інструментів читання (`mcp__planner__*`), а пароль до нього не потрапляє: `planner.env` лежить у `~/AppData`, яку інструментам Claude читати заборонено, і читає його лише сам Python-процес Джарвіса та MCP-сервер планера.
Вручну замість скрипта: `docs/planner-readonly.sql`. Час: як у планері — особистий пояс користувача, інакше пояс робочого простору (Settings), інакше годинник ПК; примусово — рядок `PLANNER_TIMEZONE=Europe/Kyiv` у `planner.env`.

## Налаштування — `config.json`

| Ключ | Що змінює |
|---|---|
| `claude_model` | `sonnet` (за замовчуванням), `haiku` — швидше, `opus` — розумніше й повільніше |
| `stt_model` | `gigaam-v3-e2e-ctc` — ~0,3 с на фразу, з пунктуацією (за замовчуванням); або розміри faster-whisper `small` / `base` |
| `tts_voice` | `ru_RU-denis-medium` (єдиний голос; завантаження — `python -m jarvis.setup_models`) |
| `proactive`, `proactive_min_seconds`, `proactive_max_seconds` | репліки з власної ініціативи та пауза тиші перед ними |
| `wake_words` | варіанти написання «Джарвис», які може видати розпізнавання |
| `follow_up_seconds` | скільки секунд після відповіді слухати без слова-активатора |
| `ptt_key` | клавіша push-to-talk (`f8` за замовчуванням, `ctrl_r`, …; `null` — вимкнути) |
| `profanity` | `true` — дозволити мат (перемикається і у вікні) |
| `mic_device`, `output_device` | номер пристрою (список: `python -c "import sounddevice; print(sounddevice.query_devices())"`) |
| `claude_allowed_tools` | інструменти, доступні Claude (shell-команди все одно проходять через дозвіл) |
| `planner_reminders`, `planner_poll_seconds` | за скільки хвилин до блоку планера нагадувати (`[10]`; `[]` — вимкнути) і як часто оновлювати план |
| `claude_disallowed_tools` | заборонені інструменти й шляхи (`~/.claude`, `~/.ssh`, `~/.aws`, `~/AppData` закриті для читання) |

## Важливо знати

- **Підписка.** Використовується незмінений `claude` з вашим входом — так дозволяють [правила Anthropic](https://code.claude.com/docs/en/legal-and-compliance) для особистого використання. Кожен, хто клонує проєкт, працює через **свій** акаунт Claude; не давайте доступ до свого Джарвіса іншим людям.
- **Ліміти.** Кожна репліка (і кожен погляд у камеру в режимі «Сам комментирует», раз на 35–70 с тиші) витрачає ліміт підписки, як звичайне повідомлення в Claude Code. Те, як Anthropic рахує фонові (`-p`) запуски, може змінюватися — стежте за використанням у налаштуваннях акаунта.
- **Ваш глобальний `~/.claude/CLAUDE.md` Джарвісу не передається** (виключено через `claudeMdExcludes`), і глобальні хуки теж (`--setting-sources project`).
- **Безпека.** Запис файлів дозволено лише в `workspace/vault`; shell-команди проходять через хук дозволу (див. вище). Якщо хочете ще суворіше — приберіть `Bash`/`PowerShell` з `claude_allowed_tools`.
- **Мікрофон працює лише при відкритому вікні**, усе розпізнається локально; у журналі фрази без звертання позначені «ПОЧУТО» і нікуди не надсилаються.
- Керувати Джарвісом може лише його власне вікно (127.0.0.1, перевірка Host і точного Origin); ендпоінт дозволів захищений одноразовим токеном.

## Розробка

```bat
python -m pytest -q tests          :: тести логіки
python -m jarvis --no-window       :: ядро без автозапуску вікна (відкрийте http://127.0.0.1:8765 вручну)
cd ui && npm run dev               :: інтерфейс з гарячим перезавантаженням (http://localhost:5173)
```

Структура: `jarvis/brain.py` (Claude), `ears.py` (мікрофон, VAD, GigaAM/Whisper), `voice.py` (Piper), `eyes.py` (камера), `core.py` (стани, слово-активатор, PTT), `server.py` (міст до вікна), `persona.py` (характер і пам'ять), `ui/` (React + Three.js).
